# Example Programs

Three complete programs, each a little larger than the examples so far and
each built around a different part of the language:

- [Word Count](word-count.md) reads a file named on the command line and
  counts its lines, words and bytes: files, arguments, structs and errors.
- [Echo Server](echo-server.md) serves many network clients at once from a
  single thread.
- [Calculator](calculator.md) reads arithmetic like `(1 + 2) * 3` and
  computes it: enums, `match`, methods and errors that travel up through
  several functions.

Copy one into a file and run it with `zeru run`.
